## Problem Statement

A cargo pilot is loading a starship and wants to maximize the total amount of energy crystals taken on board. There are m cargo groups, and in the i-th group there are ai pods, each pod containing bi crystals. All pods have the same size. The ship can hold exactly n pods. Determine the maximum number of crystals the pilot can carry. There is no time to open or rearrange pods, so the pilot simply chooses at most n pods so that the total number of crystals in them is as large as possible.

## Input

```
The first line contains integers n (1 ≤ n ≤ 2·108) and m (1 ≤ m ≤ 20). Each of the next m lines contains two integers ai and bi (1 ≤ ai ≤ 108, 1 ≤ bi ≤ 10). All input values are integers.
```

## Output

```
Print a single integer — the answer to the problem.
```
